# נירוקס, אפשרות 2

אתר סטטי מלא בעברית, המבוסס על המוקאפ של אפשרות 2. לא נדרשת התקנה, בנייה או גישה לאינטרנט.

## פתיחה

חלצו את קובץ ה-ZIP ופתחו את index.html בדפדפן. השאירו את כל הקבצים והתיקיות באותו מבנה. אין צורך להפעיל שרת.

## קבצים

- index.html: עמוד הבית
- about.html: אודות
- treatments.html: הטיפולים ושאלות נפוצות
- testimonials.html: מטופלים ממליצים
- contact.html: יצירת קשר
- styles.css: כל העיצוב וההתאמה לנייד
- script.js: תפריט נייד וטפסי הדגמה
- assets/: צילום שחולץ מהמוקאפ, לוגו, אייקון וגופני Heebo מקומיים
- design-reference.png: מוקאפ אפשרות 2 להשוואה

## התאמת תוכן

החליפו את הפרטים בסוגריים המרובעים בפרטים האמיתיים. עמוד הבית שומר על הכיתוב הקצר שבמוקאפ. יש לעדכן את שמות הטיפולים גם בכרטיסי עמוד הבית. המלצות והכשרות אינן מומצאות ויש להשלים אותן לפני שימוש אמיתי.

הטפסים מבצעים בדיקת שדות מקומית ומציגים הודעת הצלחה בלבד. לא נעשית שליחת מידע, שמירה מקומית, פנייה לשרת או פתיחת דוא״ל. הודעת ההצלחה מסומנת כהדגמה. כדי לקבל פניות אמיתיות יש לחבר שירות מתאים בהמשך.

## עיצוב

הצילום והלוגו חולצו מהמוקאפ המקורי. תצלום הטיפול הוא תמונה שנוצרה להמחשה ואינו מציג בהכרח את המטפל או הקליניקה. במחשב נשמר המבנה של אפשרות 2. בנייד התמונה מופיעה לפני הכותרת, לפי הבקשה. יתר העמודים ממשיכים את אותה שפה עיצובית.

הקוד בנוי מרכיבי HTML חיים עם CSS וטקסט אמיתי, ולא מצילום של כל העמוד. לכן ייתכנו הבדלי רינדור קלים ביחס למוקאפ המאויר ובין דפדפנים. המוקאפ המקורי מצורף להשוואה.
